📅 NEI Calendar

NEI Calendar is a simple, clean, and easy-to-use calendar app designed to help you manage your dates and events.

✨ Features

- 🌙 Dark Mode for comfortable viewing
- 📋 Separate Event Sheet for managing events
- 🗓️ Calendar-Based Date Management
- 🎨 Simple & Clean UI
- ⚡ Easy to Use

🎯 Purpose

NEI Calendar helps users keep track of important dates and events in a simple and organized way without unnecessary complexity.

📱 App Type

Calendar / Date Management App

🚀 Project

This project is developed as a simple and user-friendly calendar application with a focus on clean design and easy navigation.
